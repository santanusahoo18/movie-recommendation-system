# 🎬 Movie Recommendation System

A Machine Learning-based web application that recommends movies similar to your selection. It suggests **10 similar movies instantly**, along with their posters.

---

## 🚀 Live Demo

https://movie-recommendation-system-ss.streamlit.app/

---

## 📌 Features

* Recommend 10 similar movies
* Displays movie posters
* Fast and interactive UI
* Works on 5,000+ movies dataset
* Deployed using Streamlit Cloud

---

## 🔍 How It Works

* Select a movie from the list
* The system uses **Cosine Similarity** to compare movies
* Shows top 10 recommended movies with posters

---

## 🛠️ Tech Stack

* Python
* Streamlit
* Machine Learning
* NLP (Natural Language Processing)
* TMDB API
